# NEX Ventas — avisos de atualização

Registro público de versões já liberadas no teste interno da Google Play. Não contém código-fonte, APKs, credenciais ou dados comerciais.

`android-internal.json` informa versão NEX, código Android, data de publicação e a página oficial do aplicativo. O app consulta este arquivo em segundo plano e mostra um aviso opcional. Acesso ao teste depende do convite e da conta Google cadastrada.

Atualizar este registro somente depois de conferir a disponibilidade da versão no Play Console. Uma compilação ou envio ao GitHub, por si só, não significa publicação na Google Play. Não publicar versões futuras, links de APK ou dados privados neste repositório.
